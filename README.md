# Бригадир

Блокнот бригадира, который сам считает деньги. Мобильное веб-приложение (PWA): работает офлайн, все данные на устройстве (IndexedDB), без сервера и регистрации.

**Приложение в интернете: https://temirlan2994.github.io/brigadir/**

## Установка на телефон (как приложение)

1. Открой https://temirlan2994.github.io/brigadir/ в Chrome на Android.
2. Меню ⋮ → «Добавить на главный экран» (или нажми подсказку «Установить»).
3. На главном экране появится значок «Бригадир» — открывается как обычное приложение, работает без интернета. APK-файл не нужен.

## APK для Android

Готовый установочный файл: **[brigadir-0.3.0.apk](https://github.com/temirlan2994/brigadir/releases/download/v0.3.0/brigadir-0.3.0.apk)** (все версии — во вкладке [Releases](https://github.com/temirlan2994/brigadir/releases)).

1. Скачай APK на телефон и открой его.
2. Android спросит разрешение на установку из этого источника — разреши.
3. На главном экране появится значок «Бригадир».

APK открывает опубликованное приложение, поэтому новые версии прилетают сами — тот же баннер «Обновить», переустанавливать APK не нужно. Ключ подписи (`android/`, в git не попадает) храни бережно: без него не собрать следующую версию APK с тем же удостоверением.

## Обновления

- Деплой автоматический: каждый пуш в ветку `main` собирает и публикует новую версию (GitHub Actions → GitHub Pages).
- Когда вышла новая версия, в приложении сверху появляется баннер **«Вышло обновление приложения — Обновить»**. Нажатие на кнопку обновляет приложение. Проверка идёт при каждом запуске и раз в час.
- Проверить вручную: Настройки → «О приложении» → «Проверить обновления».
- Данные при обновлении не трогаются — они лежат в IndexedDB на устройстве.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173.

## Открыть на телефоне (та же сеть Wi-Fi)

```bash
npm run dev -- --host
```

В консоли появится адрес вида `http://192.168.x.x:5173` — открой его в Chrome на Android.

## Установка как приложение (PWA)

1. Собери и подними прод-версию: `npm run build && npm run preview -- --host`.
2. Открой адрес на телефоне в Chrome.
3. Меню ⋮ → «Добавить на главный экран». После первой загрузки работает без интернета.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск разработки |
| `npm run build` | сборка в `dist/` (статика для Vercel/Netlify/GitHub Pages) |
| `npm run preview` | предпросмотр сборки |
| `npm run typecheck` | проверка типов |
| `npm run lint` | линтер |
| `npm run test` | юнит-тесты ядра с покрытием |
| `npm run e2e` | e2e-тесты (Playwright) |
| `npm run screenshots` | скриншоты всех экранов в `screenshots/` |

## Проверка сценария «Самат» (2 минуты)

1. Первый запуск → «Начать с чистого».
2. Вкладка «Рабочие» → «+ Рабочий» → Азамат; ещё раз → Нурлан.
3. Главная → «Сделали работу» → Сварка → 1200 (кг), цены 65/45 уже подставлены → Дальше → отметить Азамата и Нурлана, Поровну → Дальше → Сохранить.
4. На главной «Мне должны 0 сом» (работа ещё не принята), запись в ленте.
5. «Получил от заказчика» → «Отметить принятые работы» → отметить сварку → «Принять выбранные». На главной «Мне должны 78 000 сом».
6. «Выдал рабочим» → Азамат → 10000 → Сохранить. «Я должен рабочим 44 000 сом».
7. «Получил от заказчика» → 50000 → Сохранить. «Мне должны 28 000 сом», «Свободно −4 000 сом» и красный баннер.
8. «Потратил» → Транспорт → 3000 → Сохранить. Касса (вкладка «Деньги») 37 000 сом.
