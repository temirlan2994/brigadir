# Бригадир

Блокнот бригадира, который сам считает деньги. Мобильное веб-приложение (PWA): работает офлайн, все данные на устройстве (IndexedDB), без сервера и регистрации. Интерфейс построен вдоль пути бригадира: взял объект → договорились о ценах → собрал бригаду → каждый день записываешь → сдал заказчику → получил деньги → рассчитался с бригадой → закрыл объект.

**Приложение в интернете: https://temirlan2994.github.io/brigadir/**

## Установка на телефон

- **Как приложение из Chrome:** открой адрес выше на Android → меню ⋮ → «Добавить на главный экран».
- **APK-файл:** [brigadir-0.3.0.apk](https://github.com/temirlan2994/brigadir/releases/download/v0.3.0/brigadir-0.3.0.apk) — скачай, открой, разреши установку. APK открывает опубликованное приложение, поэтому обновления прилетают сами, переустанавливать не нужно.

## Как устроено

Четыре вкладки снизу:

- **Сегодня** — свободно ли на зарплату, одна большая кнопка «Записать работу», выдал / потратил / получил, кто сегодня вышел, лента.
- **Объекты** — каждый объект со стадией (взял → работаем → сдаём → получаем → закрыл) и кнопка «Взял новый объект». Внутри объекта: Работы, Сдача заказчику (приёмка галочками, частичная приёмка, акт, отчёт в WhatsApp), Деньги заказчика (аванс, оплаты, удержания), Цены и заказчик, Итог объекта, Закрыть объект.
- **Бригада** — кому сколько должен, выдача, выписка в WhatsApp.
- **Касса** — деньги по всем объектам: из чего сложилось, хватит ли на зарплату, «взял себе» / «вложил свои», выгрузка в таблицу.

Шестерёнка на «Сегодня» — настройки программы: язык, налог, начальный остаток кассы, справочник видов работ, резервная копия, обновления. Объекты и цены там не живут — они внутри объекта.

Кнопка «Показать заказчику» на экранах объекта прячет цены бригады и прибыль.

## Обновления

Каждый пуш в `main` публикует новую версию. В открытом приложении появляется баннер «Вышло обновление — Обновить»; проверка при запуске, раз в час и вручную в настройках. Данные при обновлении не трогаются.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. На телефоне в той же сети: `npm run dev -- --host`.

| Команда | Что делает |
|---|---|
| `npm run build` | сборка в `dist/` |
| `npm run typecheck` · `npm run lint` | проверки |
| `npm run test` | юнит-тесты ядра с покрытием |
| `npm run e2e` | e2e (Playwright) |
| `npm run screenshots` | скриншоты экранов в `screenshots/` |

## Проверка сценария «Самат» (2 минуты)

1. Первый запуск → «Взял объект»: название, заказчик → Дальше → цены (Сварка 65/45 уже отмечена) → Дальше → бригада: Азамат, «Ещё один», Нурлан → «Начать работу».
2. «Записать работу за сегодня» → Сварка → 1200 → Дальше → Азамат и Нурлан отмечены → Дальше → Сохранить. На «Сегодня»: бригаде должен 54 000, ещё не сдано 78 000.
3. Нажми «Ещё не сдано» → отметь сварку → «Принято заказчиком». На «Сегодня»: заказчик должен 78 000.
4. «Выдал» → Азамат → 10000 → Сохранить. Бригаде должен 44 000.
5. «Получил» → 50000 → Сохранить. Заказчик должен 28 000, «Свободно на зарплату −4 000 · не хватает».
6. «Потратил» → Транспорт → 3000. Касса (вкладка «Касса») 37 000.
