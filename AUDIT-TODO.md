# Находки аудита интерфейса — все исправлены в версии 0.6.0 (23 октября)

Как исправлено:

- **Заметка терялась при системном «Назад»** → сохраняется на лету (onChange с задержкой 0,6 с) и при уходе с экрана.
- **Шторки с вводом закрывались тапом мимо и теряли ввод** → общий компонент Sheet: тап по затемнению при открытой клавиатуре только убирает клавиатуру; закрытие — второй тап или явная «Отмена».
- **Печать акта мертва в установленном приложении** → главная кнопка теперь «Отправить акт» (текст в WhatsApp/буфер); «Печать» показывается только в браузере.
- **Скачивание копии/CSV молча не работало на iPhone** → в установленном приложении файл отдаётся через системное «Поделиться» (WhatsApp, Файлы), в браузере — обычное скачивание.
- **Экспорт CSV стрелял пятью скачиваниями** → один файл brigadir.csv с разделами.
- **Архивный/закрытый объект был тупиком** → карточка ведёт на экран объекта; там кнопка «Открыть объект заново» / «Вернуть из архива», вся история доступна.
- **Стрелка «Назад» мертва после перезагрузки** → при пустой истории ведёт на «Сегодня».
- **Импорт копии стирал базу до вставки** → очистка и вставка в одной транзакции: битый файл откатывается целиком.
- **Двойной тап «Сохранить» создавал две записи** → защита от повторного сабмита во всех формах и удалениях.
- **«Загрузить пример» без предупреждения поверх реальных данных** → подтверждение.
- **Черновик мастера терялся при звонке/камере** → живёт в localStorage и восстанавливается на том же шаге.
- **Фото падало молча на битых файлах** → сжатие с запасным путём (кладём исходник), без падения.
- **Правка заказчика сохранялась только кнопкой** → автосохранение через секунду после правки.
- **Серый «Сохранить» при ручном делении без объяснения** → остаток показан и на шаге «Проверь».
- **Выдача писалась на текущий объект, а не на объект долга** → если долг бригадира накоплен на одном объекте, выдача пишется туда.
- **Мастер нового объекта после перезагрузки на шаге 3** → возврат на первый шаг при пустых полях.
