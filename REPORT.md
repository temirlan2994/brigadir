# Утренний отчёт — версия 2

Интерфейс переписан с нуля вдоль пути бригадира. Приложение опубликовано на https://temirlan2994.github.io/brigadir/ и приедет в установленный APK само (баннер «Обновить»).

## Как запустить

```bash
npm install
npm run dev
```

На телефоне — просто открой https://temirlan2994.github.io/brigadir/ или установленный APK: он обновится при следующем запуске (проверка при старте, раз в час и вручную в настройках).

## Что сделано — по пути бригадира

1. **Взял объект** — мастер из трёх шагов вместо пункта в настройках: объект и заказчик (телефон, как платит, аванс при старте) → о каких ценах договорились (галочки по видам работ, две цены в строке) → кто в бригаде. Он же — первый запуск.
2. **Каждый день** — вкладка «Сегодня»: первым идёт «Свободно на зарплату» (хватает / не хватает), ниже заказчик должен и ещё не сдано, одна жёлтая кнопка «Записать работу за сегодня», выдал / потратил / получил, «кто сегодня вышел», лента по дням. После 18:00 — подсказка, если ничего не записано.
3. **Сдал объёмы** — внутри объекта «Сдача заказчику»: галочки «принято», сумма выбранного, **частичная приёмка** («принято 450 из 500»), остаток остаётся в «не принято», акт, **отчёт заказчику в WhatsApp**.
4. **Получил деньги** — «Деньги заказчика»: оплаты и **авансы** (показывается «аванс: отработать N», а не «переплатил»), удержания и штрафы.
5. **Рассчитался с бригадой** — вкладка «Бригада» с «осталось выдать» и «Рассчитаться», карточка рабочего по дням, выписка в WhatsApp.
6. **Касса** — по всем объектам: из чего сложилось, хватит ли на зарплату, **«взял себе» / «вложил свои»** (чтобы касса совпадала с карманом), выгрузка в таблицу.
7. **Закрыл объект** — «Закрыть объект» как проверка: всё принято? заказчик заплатил? бригада рассчитана? Потом «Итог объекта»: заработал, сколько в день, что съело деньги.
8. **Стадии объекта** считаются сами (взял → работаем → сдаём → получаем), руками только «закрыл».
9. **Показать заказчику** — кнопка на экранах объекта прячет цены бригады и прибыль.
10. **Ярлыки** на долгое нажатие иконки: «Записать работу», «Выдал».

Настройки программы теперь только про программу: язык, налог, остаток кассы, справочник видов работ, копия, обновления.

## Проверено

- Юнит-тесты ядра: 40, покрытие 100% (частичная приёмка, аванс, личные движения кассы, стадии).
- E2E 11 сценариев: «Самат» целиком по новому интерфейсу, частичная приёмка, аванс заказчика, «как вчера», перезагрузка, закрытие объекта, офлайн, копия, ширины 360/430, скриншоты. Все зелёные (один нестабилен на холодном старте сервера, проходит с повтора).
- Руками в браузере: мастер нового объекта → сварка 1 200 кг с ценами из мастера → частичная приёмка → оплата → выдача → касса → «взял себе». Числа сходятся до сома.
- Ревью-воркфлоу (четыре ревьюера + адверсальная проверка каждой находки) — результаты и исправления в DECISIONS.md.

## Что не сделано или урезано

- Вечернее напоминание — только подсказка внутри приложения; настоящие push без сервера в PWA невозможны.
- «Кто вышел» — одна строка галочек в день, без табеля часов; подставляет бригаду в запись работы.
- Отчёт заказчику — текст в WhatsApp; фото нужно прикладывать отдельно (wa.me не умеет вложения).
- Режим «показать заказчику» живёт до перезапуска приложения.
- Старые записи (до версии 2) открываются без изменений: поля частичной приёмки и вида поступления у них пустые — считаются как раньше.

## Известные шероховатости

- Длинные названия объектов в заголовке переносятся на две строки.
- На «Сегодня» лента показывает записи только активного объекта; личные движения кассы видны в «Кассе».
- Итог открытого объекта — прогноз по выполненному; факт по деньгам появляется после закрытия.

## Что делать следующим

1. Неделя на реальном объекте Самата: записывать по вечерам, отметить, где он спотыкается.
2. Проверить APK на телефоне: баннер обновления, «Назад», нампад, ярлыки на иконке.
3. Пересмотреть кыргызские тексты с носителем — словарь переписан полностью, перевод черновой.
4. Решить про напоминание: если нужно настоящее — потребуется маленький сервер для push.
5. По итогам недели — табель смен и материалы, если без них действительно неудобно.
